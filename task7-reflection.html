My HTML Learning Reflection

Week 1 – HTML Learning
A short reflection on what I learned and experienced.

What I Learned

During Week 1, I learned the basics of HTML and how to create the structure of a webpage. I learned how to use headings, paragraphs, text formatting, links, images, lists, tables, and forms.

I also learned about semantic HTML tags such as header, nav, main, section, article, and footer. Creating different HTML pages helped me understand how these elements work together to build a complete webpage.

My Challenge

The most challenging topic for me was HTML forms because there are many different input types, such as text, email, telephone, radio buttons, checkboxes, dropdowns, and textareas.

Understanding how to organize all these elements properly required some practice.

What I Enjoyed

I enjoyed working with links, images, lists, and forms the most because I could see the webpage becoming more useful and interactive.

Creating the Mini HTML Project was also enjoyable because it allowed me to combine the concepts I learned throughout the week.

How HTML Will Help Me

HTML will help me in learning web development because it provides the basic structure of every webpage.

In the future, I can use CSS to style my HTML pages and JavaScript to add functionality. This Week 1 practice has given me a strong foundation for learning more advanced web development concepts.

End of Week 1 Reflection
